**Solano City** is an original top-down open-world crime game in vanilla HTML5 canvas and ES modules. You play Rico Vale, a wheelman back in his home city for one more run. Explore a sun-soaked grid of streets, parks, a beach and a working waterfront on foot or behind the wheel. Steal cars, jack traffic, dodge pedestrians, earn a five-star wanted level, and work an eight-mission story chain for Mama Cielo, Tito, Nadia, Detective Rusk and Bishop.

Everything is local: no build step, no network requests, no external art, sound or music. The city, characters, vehicles, story, synthesized audio and minimap are generated by the game's own code.

## Run it

```sh
cd game && python3 -m http.server 8000
```

Open <http://localhost:8000> in desktop Chrome. Click **New Game** (or press Enter). The game needs a user gesture before it can start the synthesized WebAudio soundtrack.

To hand the entry in:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `game/` and `screenshots/` into the output directory, scans the game for network URLs, and writes `out/dossier.json` with the vendored `buildDossier` helper.

## Layout

```
main.ts                 Node 22 handoff: copy, scan, dossier, summary
game/
  index.html            one page, one module entry
  src/
    config.js           tuning, palettes, weapons, car types
    utils.js            math, collision, formatting, RNG
    city.js             tiled city, roads, blocks, parks, beach, minimap tiles
    player.js           walk, run, aim, shoot, enter and exit vehicles
    vehicles.js         arcade car physics, drift, damage, parked cars
    traffic.js          lane-following civilian traffic and carjacking targets
    peds.js             wandering pedestrians, panic, gunfire and horn reactions
    police.js           cruisers and foot officers responding to the wanted level
    wanted.js           five stars with delay and decay
    combat.js           bullets, melee, damage, weapon and health pickups
    particles.js        muzzle flash, sparks, blood, smoke and explosions
    missions.js         eight-mission chain: markers, timers, fails, rewards
    story.js            mission text and phone-call intros
    hud.js              health, armour, money, weapon, stars, calls, objective
    minimap.js          rotating circular minimap with blips
    menus.js            title, pause, controls, settings, save and load slots
    savegame.js         localStorage slots, autosave and settings
    audio.js            synthesized engine, guns, sirens, horns and music
    camera.js           smooth follow, look-ahead and screen shake
    render.js           draw order, golden-hour lighting, vignette
    main.js             input, fixed-timestep loop and state machine
screenshots/            four in-game renders, cover first by name
vendor/                 the kit's dossier library, unchanged
```

## Controls

| Input | Action |
| --- | --- |
| `W A S D` / arrows | Walk, or drive |
| `Shift` | Run |
| Mouse | Aim |
| Left click | Shoot, or punch with fists |
| `F` | Enter or exit a car; on an occupied car this carjacks it |
| `Space` | Handbrake / drift |
| `1` `2` `3` `4` | Fists, pistol, SMG, shotgun |
| `H` | Horn; nearby pedestrians panic and traffic answers |
| `M` | Toggle the rotating minimap |
| `Esc` | Pause menu, save, load, controls and settings |

## The city and its systems

- **Driving:** acceleration, braking, reverse, lateral grip, handbrake drift, building and water collisions, vehicle health, smoke, fire and explosions. Parked cars are free; occupied cars are a crime.
- **Traffic:** civilian cars follow lanes at their own speed, slow for each other and for you, turn at intersections, honk when stuck and panic nearby pedestrians.
- **Pedestrians:** wander the sidewalks and parks, flee gunfire, panic at horns, and can be hit by cars. Some are mission targets in red.
- **Police and wanted:** one star brings a cruiser; two or more add foot officers who pursue and shoot. Stars decay after a quiet spell, unless a mission is holding the heat on.
- **Combat:** four weapons, spread and pellets, bullet travel, wall and water impacts, vehicle damage, melee, armour absorption, health and ammo drops, money drops.
- **Story:** eight jobs with phone-call intros, gold markers, timed objectives, collect and kill steps, survive and escape steps, a mission-car delivery, fail states and money rewards.
- **Persistence:** three manual save slots plus autosave, stored in `localStorage`, with settings for master volume, music and the rotating minimap.
- **Presentation:** golden-hour grade, sun glow, vignette, screen shake, muzzle and impact effects, a rotating minimap with mission, police, traffic and package blips, and a synthesized soundtrack.

## Verification

```sh
for f in game/src/*.js; do node --input-type=module --check < "$f" || exit 1; done
grep -rE 'https?://' game/          # must print nothing
cd game && python3 -m http.server 8127   # GET / returns 200
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The game is original work. No Rockstar Games names, characters, map, art, music or assets are used.
